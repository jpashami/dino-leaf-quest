# 🦕 Pip's Leaf Quest

A tiny, kid-friendly dinosaur game. One HTML file, no install, no internet needed.

**Play online:** https://jpashami.github.io/dino-leaf-quest/

**To play offline:** double-click `index.html` (opens in any web browser — works on tablets too).

- Arrow keys / WASD, or tap & hold where Pip should walk
- Eat leaves 🍃 to grow stronger (golden leaves = 3 points)
- Twinkling bushes hide leaves; rocks with a green crack can be smashed once Pip is Strong
- SPACE or the ROAR button (from level 5) shakes leaves out of everything nearby
- **⏸ Menu** button (or ESC / P) pauses: Keep Playing, 🔄 Restart, or 🏠 Exit to Start

No enemies, no losing — just exploring and growing. The full story is in [STORY.md](STORY.md).
